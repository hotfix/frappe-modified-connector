# Security policy

## Supported versions

Security fixes are made for the latest release only. Please update to the latest release before reporting.

## Reporting a vulnerability

Please do **not** report security issues in public issues, pull requests or discussions.

Report them privately through GitHub: open the **Security** tab of this repository and click
**Report a vulnerability**
([direct link](https://github.com/hotfix/frappe-modified-connector/security/advisories/new)).

Please include:

- what an attacker can do, and which role or access they need,
- the steps to reproduce it,
- the versions of Frappe, ERPNext, this app and modified eCommerce.

Do not include real credentials, shop URLs or customer data. The project is maintained in spare time, so there
is no guaranteed response time, but security reports are handled first. Once a fix is released, the report
is published as a security advisory, with credit to you if you wish.
